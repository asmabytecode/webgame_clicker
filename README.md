# Сектор Ноль

Кликер на React с Node.js API и SQLite. Для каждого аккаунта создаётся отдельный SQLite-файл с игровым состоянием; в общей базе аккаунтов хранятся ники, хеши паролей и сессии.

## Структура

- `src/App.jsx` — точка композиции: сессия, выбор экрана и подготовка данных для игрового интерфейса.
- `src/hooks/useGameSession.js` — загрузка аккаунта, синхронизация прогресса, игровые действия и уведомления.
- `src/components/game/` — все игровые экраны и панели; `ProgressionPanels.jsx` и `UpgradeTrees.jsx` содержат общие компоненты игровых систем.
- `src/components/` — экраны и компоненты верхнего уровня, включая форму авторизации.
- `src/styles.css` подключает стили в фиксированном порядке: базовые (`src/styles/base.css`), панели (`dashboard.css`), игровой экран (`gameplay.css`) и палитра (`theme.css`).
- `src/lib/api.js` — HTTP-клиент; `src/lib/actionFeedback.js` — тексты обратной связи; `src/lib/gameViewModel.js` — производные данные для интерфейса.
- `src/lib/gameMath.js` — форматирование и расчёты только для интерфейса; `shared/gameMath.js` — единые формулы экономики для клиента и сервера.
- `shared/gameData.js` — каталог улучшений, заданий и этапов, общий для интерфейса и игровых правил.
- `server/gameState.js` — создание, проверка и нормализация сохранений; `server/gameEconomy.js` — начисление дохода и прогресс контрактов; `server/game.js` — допустимые игровые действия и правила престижа.
- `server/database.js` — SQLite-хранилища аккаунтов и игровых состояний; `server/services/` — операции аккаунта и игрового домена.
- `server/middleware/` и `server/routes/` — HTTP-аутентификация, ограничение запросов и маршруты API; `server/app.js` собирает приложение, а `server/index.js` запускает сервер.
- `shared/leaderboardData.js` задаёт категории таблицы лидеров; сервер формирует общий топ игроков по совокупным CR, кликам, возрождениям и экспедициям.
- В деревьях улучшений кнопка `MAX` покупает все уровни выбранного улучшения, которые можно оплатить текущей валютой. Цены и балансы подсвечиваются разными цветами для CR, SOUL, DATA и RELIC.

## Запуск для разработки

1. Установите Node.js 20.19+ или 22.12+.
2. В каталоге проекта выполните `npm install`.
3. Запустите `npm run dev`.
4. Откройте `http://127.0.0.1:5173`.

Не открывайте `index.html` двойным щелчком: для входа и сохранений одновременно должны работать интерфейс и API, которые запускает `npm run dev`.

Для production-сборки выполните `npm run build`, затем `npm start`. Сервер Node.js обслуживает API и собранный интерфейс на порту `3001` (или на порту из переменной окружения `PORT`).

Игровые базы создаются в `data/users/<id>/game.sqlite`, а реестр аккаунтов — в `data/accounts.sqlite`. Каталог `data` исключён из Git. Для переноса сохранений остановите сервер и сохраните весь этот каталог.

Пароли не хранятся в открытом виде: сервер использует `scrypt` с отдельной случайной солью. Сессии передаются через HttpOnly cookie. Приложение предназначено для локального запуска; перед публикацией в интернете настройте HTTPS и соответствующую инфраструктуру.

## Игровой цикл и баланс

- **CR (кредиты)** добываются кликами и автоматизацией; дерево производства сбрасывается при обоих видах престижа.
- Автоматизация — основной источник прогресса: автодоход складывается из ботов, разгона, исследований и общего множителя. В интерфейсе отдельно показаны базовый темп и активные множители; ветки улучшений свёрнуты, кроме автоматизации.
- **Контур синхронизации** открывается после 3 уровней разгона процессора. Каждый его уровень добавляет +1% к автодоходу за каждые 25 ручных кликов в забеге; бонус ограничен +100%. Так ручные нажатия ускоряют автоматический цикл, но не становятся обязательной постоянной рутиной.
- **DATA (данные)** выдаются за три ежедневных контракта. Лаборатория сохраняется при сбросах и развивает силу клика, автоматизацию и лимит офлайн-дохода.
- **SOUL (души)** выдаются за возрождение от 10 000 CR за забег. Награда растёт по формуле `floor(sqrt(CR за забег / 10 000) × бонус артефактов)`.
- **RELIC (реликвии)** выдаются за смену сектора от 50 000 CR за забег по формуле `floor(sqrt(CR за забег / 50 000))` и за семь постоянных этапов кампании: 1k, 5k, 25k, 75k, 150k, 500k и 2M совокупных CR. Мастерская улучшает доход, награду SOUL, стартовый капитал и офлайн-хранилище.
- Возрождение нацелено на короткий престижный цикл; смена сектора — на более длинный. Оба сохраняют лабораторию, журнал кампании и постоянные улучшения. Кнопка «Стереть данные» удаляет весь прогресс без награды.
- Офлайн-доход ограничен 8 часами по умолчанию. Лаборатория и артефакты увеличивают запас хранения, общий предел — 24 часа.
- Ежедневные задания обновляются в полночь UTC. Их прогресс сохраняется при престиже, но награда за каждый контракт выдаётся один раз в день.

`npm test` содержит детерминированную семидневную модель: около 240 кликов за сессию, покупки доступной автоматизации и до 8 часов накопления дохода в сутки. В модели игрок сначала выбирает возрождение, затем смену сектора, выполняет контракты и вкладывает постоянные валюты; последний этап на 2M совокупных CR достигается ближе к концу тестовой недели. Это ориентир для активного ежедневного входа, а не обещание фиксированного реального времени: темп зависит от навыков, кликов и пропущенных дней.

## Проверки

- `npm test` — правила экономики, валюты, контрактов, престижа и семидневная модель.
- `npm run build` — production-сборка React-интерфейса.
