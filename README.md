# Сектор Ноль

Кликер на React с Node.js API и SQLite. Для каждого аккаунта создаётся отдельный SQLite-файл с игровым состоянием; в общей базе аккаунтов хранятся ники, хеши паролей и сессии.

## Архитектура

Код сгруппирован по ответственности и игровым функциям. Клиентские импорты используют алиасы `@/` для `src/` и `@shared/` для общего домена.

```text
src/
  app/                 Композиция приложения и выбор экранов
  features/
    auth/              Вход и регистрация
    game/
      components/
        dashboard/     Основной игровой экран и показатели
        progression/   Престиж, экспедиция, достижения и профиль
        upgrades/      Деревья улучшений
      hooks/           Игровая сессия и синхронизация с API
      lib/             Представление игры, расчёты UI и обратная связь
    leaderboard/       Таблица лидеров
  shared/api/          Общий HTTP-клиент интерфейса
  styles/              Базовые, экранные и тематические стили
  main.jsx             Точка входа React

server/
  features/
    auth/              Маршруты, сервисы и middleware аутентификации
    game/              Правила игры, экономика, состояние и API игрового домена
      tests/           Игровые и балансовые тесты
    leaderboard/       Сервис рейтинга и его тесты
  infrastructure/      SQLite и файловое хранилище
  app.js               Сборка Express-приложения
  index.js             Запуск сервера

shared/
  game/                Общие игровые данные и формулы экономики
  leaderboard/         Категории рейтинга
```

Формулы и каталоги в `shared/` — единый источник правил для клиента и сервера. `server/features/` держит рядом обработчики, маршруты и логику каждой функции; SQLite вынесен в `server/infrastructure/`.

`src/styles.css` подключает базовые стили, стили панели, игрового экрана и темы в фиксированном порядке. Производная модель и форматирование интерфейса находятся в `src/features/game/lib/`; сетевой клиент — в `src/shared/api/`.

- В деревьях улучшений кнопка `MAX` покупает все уровни выбранного улучшения, которые можно оплатить текущей валютой. Цены и балансы подсвечиваются разными цветами для CR, SOUL, RELIC и CORE.

## Запуск для разработки

1. Установите Node.js 20.19+ или 22.12+.
2. В каталоге проекта выполните `npm install`.
3. Запустите `npm run dev`.
4. Откройте `http://127.0.0.1:5173`.

Не открывайте `index.html` двойным щелчком: для входа и сохранений одновременно должны работать интерфейс и API, которые запускает `npm run dev`.

Для production-сборки выполните `npm run build`, затем `npm start`. Сервер Node.js обслуживает API и собранный интерфейс на порту `3001` (или на порту из переменной окружения `PORT`).

Игровые базы создаются в `data/users/<id>/game.sqlite`, а реестр аккаунтов — в `data/accounts.sqlite`. Каталог `data` исключён из Git. Для переноса сохранений остановите сервер и сохраните весь этот каталог.

Пароли не хранятся в открытом виде: сервер использует `scrypt` с отдельной случайной солью. Сессии передаются через HttpOnly cookie. Приложение предназначено для локального запуска; перед публикацией в интернете настройте HTTPS и соответствующую инфраструктуру.

## Игровой цикл и баланс

- **CR (кредиты)** добываются кликами и автоматизацией; дерево производства сбрасывается при обоих видах престижа.
- Автоматизация — основной источник прогресса: автодоход складывается из ботов, разгона и постоянных множителей. В интерфейсе отдельно показаны базовый темп и активные множители; ветки улучшений свёрнуты, кроме автоматизации.
- **Контур синхронизации** открывается после 3 уровней разгона процессора. Каждый его уровень добавляет +1% к автодоходу за каждые 25 ручных кликов в забеге; бонус ограничен +100%. Так ручные нажатия ускоряют автоматический цикл, но не становятся обязательной постоянной рутиной.
- **SOUL (души)** выдаются за возрождение от 10 000 CR за забег. Награда растёт по формуле `floor(sqrt(CR за забег / 10 000) × бонус артефактов)`.
- Постоянные улучшения клика и автодохода за SOUL дают +10% за уровень вместо фиксированных +2 CR. Стартовый капитал даёт 1 000 CR за уровень SOUL и 5 000 CR за уровень RELIC. Ветви клика и производства растут вместе с ценой уровня, чтобы дорогие покупки сохраняли заметную отдачу.
- **RELIC (реликвии)** выдаются за смену сектора от 50 000 CR за забег по формуле `floor(sqrt(CR за забег / 50 000))` и за семь постоянных этапов кампании: 1k, 5k, 25k, 75k, 150k, 500k и 2M совокупных CR. Мастерская улучшает доход, награду SOUL, стартовый капитал и офлайн-хранилище.
- **CORE (ядра)** выдаются за вознесение — третий уровень престижа после первого возрождения и 1M CR за забег. Награда равна `floor(sqrt(CR за забег / 1 000 000))`; постоянное древо усиливает общий доход, клик, автоматизацию, стартовый капитал, награду SOUL и офлайн-хранилище.
- Сектора чередуются после экспедиции и меняют баланс кликов и автодохода. Доход наносит урон боссам; победы дают RELIC и до трёх собираемых артефактов. Активным может быть только один артефакт.
- Достижения отслеживают клики, боссов, сектора и общий заработок; главы кампании продолжаются после 2M CR вплоть до 500M.
- Возрождение нацелено на короткий цикл, смена сектора — на более длинный, вознесение — на позднюю игру. Сбросы сохраняют постоянные древа и общий прогресс. Кнопка «Стереть данные» удаляет весь прогресс без награды.
- Офлайн-доход ограничен 8 часами по умолчанию. Мастерская, вознесение и артефакты увеличивают запас хранения, общий предел — 24 часа.
- **Казуальный режим** включает серверный автопилот: он забирает доступные награды, выбирает улучшения и выполняет доступный престиж, сравнивая ожидаемый автодоход после сброса. Пока игра открыта, решения принимаются при синхронизации состояния; после возвращения сначала учитывается офлайн-доход. Автопилот не выполняется в реальном времени, пока игра закрыта.

`npm test` содержит детерминированную семидневную модель: около 240 кликов за сессию, покупки доступной автоматизации и до 8 часов накопления дохода в сутки. Производящие улучшения в этой модели масштабируются вместе с ценой уровня. Это ориентир для активного ежедневного входа, а не обещание фиксированного реального времени: темп зависит от навыков, кликов и пропущенных дней.
